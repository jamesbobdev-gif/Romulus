---
name: 3D model sites
sites: makerworld.com, thingiverse.com, printables.com
---
- These sites **block read_page** (bot checks), so a blocked page doesn't mean the model is gone.
  Work from search results, or open the page in the browser if you have one.
- Link the **model's own page** (makerworld.com/en/models/…, thingiverse.com/thing:…,
  printables.com/model/…), never a search, tag or collection page.
- MakerWorld models often come with a ready Bambu Lab print profile; mention it if the page shows one.
- Check the model fits: the description or photos usually give sizes (e.g. desk thickness for clamps).
