Devices

Set up by hand

For your first device, or your own Supabase project. One project, one sync key: the same three values on every device sync every list. Keep the sync key private.

A Supabase project of your own. Its free plan holds 500 MB; Pro is $25 a month. It takes about ten minutes, once:

  1. Make a free account and a New project at Supabase. Any name and region will do.
  2. Press Copy setup.sql below. In the project, open SQL Editor, paste it and press Run.
  3. In Project Settings → API, copy the Project URL and the publishable key into the first two boxes below. Never use the secret key.
  4. Press Save & sync. A sync key is made for you. Then press Add a device above for your phone.
Per-list keys (optional)

The Work, Agent and School lists get their own keys made from the sync key above, so they sync wherever it does. Type a key here only to share one list with a different key (for example a Work list shared with a colleague).
